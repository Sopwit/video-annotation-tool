# ⌨️ Keyboard Shortcuts Reference

Complete list of keyboard shortcuts supported by the **Video Annotation Tool**.

---

## 🎨 Drawing & Annotation Tools

| Shortcut | Tool | Description |
| :--- | :--- | :--- |
| `P` | **Pen** | Freehand drawing tool with adjustable stroke width and color |
| `E` | **Eraser** | Eraser tool to remove annotations on the active layer |
| `C` | **Cursor** | Selection and inspection cursor mode |
| `T` | **Text** | Place text annotations on the canvas |
| `S` | **Stamp** | Place emoji stamps (✅, ❌, ❓, ❗, ⭐, 🎯) |

---

## 📐 Shape Tools

| Shortcut | Tool | Description |
| :--- | :--- | :--- |
| `R` | **Rectangle** | Draw rectangles / bounding boxes |
| `O` | **Circle** | Draw circles and ellipses |
| `A` | **Arrow** | Draw directional pointer arrows |
| `L` | **Line** | Draw straight lines |

---

## 🎬 Video & Playback Controls

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Space` | **Play / Pause** | Toggle video playback |
| `Left Arrow` | **Previous Frame** | Step back 1 frame (1/30 sec) |
| `Right Arrow` | **Next Frame** | Step forward 1 frame (1/30 sec) |
| `Shift + Left Arrow` | **Back 1 Second** | Jump backward by 1 second |
| `Shift + Right Arrow` | **Forward 1 Second** | Jump forward by 1 second |
| `Home` | **Start** | Jump to the beginning of the video |
| `End` | **End** | Jump to the end of the video |

---

## 🔍 Canvas Zoom & Pan

| Action | Control | Description |
| :--- | :--- | :--- |
| **Zoom In / Out** | `Ctrl/Cmd + Mouse Wheel` | Smooth zoom up to 500% |
| **Pan Canvas** | `Shift + Drag` or `Middle Mouse Drag` | Move around the zoomed canvas |
| **Reset View** | `Esc` | Reset zoom to 100% and center pan |

---

## 💾 Project & History

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Ctrl/Cmd + Z` | **Undo** | Undo last drawing action |
| `Ctrl/Cmd + Shift + Z` / `Ctrl/Cmd + Y` | **Redo** | Redo previously undone action |
| `Ctrl/Cmd + S` | **Save Project** | Save annotations and project state to IndexedDB |
| `Ctrl/Cmd + E` | **Export PNG** | Export current composite frame as PNG |

---

## 🪟 Panels & Overlays

| Shortcut | Panel | Description |
| :--- | :--- | :--- |
| `Ctrl/Cmd + B` | **Bookmarks** | Toggle Notes & Bookmarks sidebar |
| `Ctrl/Cmd + L` | **Layers** | Toggle Layer Manager panel |
| `Ctrl/Cmd + T` | **Timeline** | Toggle interactive timeline scrubber |
| `Ctrl/Cmd + ,` | **Settings** | Open Settings and storage dialog |
| `?` | **Help** | Open shortcut reference overlay |
| `Esc` | **Close Dialogs** | Close any active modal dialog |

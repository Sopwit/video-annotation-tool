# 👋 Contributing to Video Annotation Tool

First off, thank you for considering contributing to Video Annotation Tool! It's people like you that make this tool such a great resource for the community.

## 📜 Code of Conduct

This project and everyone participating in it is governed by the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior to [sopwit@osdev.shop](mailto:sopwit@osdev.shop).

---

## 🛠️ How Can I Contribute?

### Local Prerequisites

- Node.js 20+
- npm 10+ (recommended)

### 🐛 Reporting Bugs

- **Ensure the bug was not already reported** by searching on GitHub under [Issues](https://github.com/Sopwit/video-annotation-tool/issues).
- If you're unable to find an open issue addressing the problem, [open a new one](https://github.com/Sopwit/video-annotation-tool/issues/new).
- Include a **title and clear description**, as well as relevant information like screenshots, logs, or steps to reproduce.

### 💡 Suggesting Enhancements

- Open a new issue in the GitHub repository describing the feature you'd like to see.
- Explain **why** you need it and **how** it should work.

### 📥 Pull Requests

1. **Fork** the repo and create your branch from `main`.
2. If you've added code that should be tested, **add tests**.
3. If you've changed APIs, **update the documentation**.
4. Ensure the quality checks pass:
   - `npm run lint`
   - `npm run test`
   - `npm run build`
5. Make sure your code follows the existing ESLint rules.
6. Issue that pull request!

---

## 🎨 Style Guides

### Git Commit Messages

- Use the **present tense** ("Add feature" not "Added feature").
- Use the **imperative mood** ("Move cursor to..." not "Moves cursor to...").
- Limit the first line to **72 characters** or less.
- Reference issues and pull requests heavily.

### JavaScript/React Styleguide

- All code must adhere to the project's **ESLint configuration**.
- Use **Functional Components** and **Hooks** for React.
- Prefer `const` over `let`. Avoid `var`.

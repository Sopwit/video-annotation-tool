## 🔄 Required Integration Steps

To activate all new features, you need to update existing components:

### 1. Update `App.jsx`

```javascript
// Replace all useState with useStore
import useStore from "./store/useStore";

const {
  videoUrl,
  setVideoUrl,
  isPlaying,
  setIsPlaying,
  tool,
  setTool,
  color,
  setColor,
  // ... etc
} = useStore();
```

### 2. Update `CanvasOverlay.jsx`

```javascript
// Add layer support
const { layers, currentLayer } = useStore();

// Render each visible layer
layers
  .filter((l) => l.visible)
  .forEach((layer) => {
    ctx.globalAlpha = layer.opacity;
    // draw layer annotations
  });
```

### 3. Update `Toolbar.jsx`

```javascript
// Add import
import { saveProject } from "../services/database";
import ExportService from "../services/exportService";

// Add save button
// Add export menu
// Add settings button
// Add timeline toggle
// Add layer panel toggle
```

### 4. Add New Components to Layout

```javascript
import Timeline from './components/Timeline';
import LayerManager from './components/LayerManager';
import SettingsPanel from './components/SettingsPanel';

// In render:
{showTimeline && <Timeline ...props />}
{showLayers && <LayerManager />}
{showSettings && <SettingsPanel ...props />}
```
